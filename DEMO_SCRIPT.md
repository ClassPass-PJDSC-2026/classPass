# ClassPass Demo Script

**Introduction (0:00 - 0:15)**

"Hello, we are the ClassPass team. Today, we are presenting our Classroom Outbreak Simulator—a decision-support tool designed to help schools see how different interventions affect the spread of airborne diseases."

**The Interface & Setup (0:15 - 0:40)**

"Let's start by looking at the control panel on the left. Here, users set up the 'School Profile'. You can adjust the class size, room dimensions, and ventilation rates. This allows you to model a scenario that accurately reflects your actual school environment."

**Running the Simulation & Results (0:40 - 1:10)**

"Once the settings are ready, we run the simulation. Moving to the Results tab, the dashboard immediately shows the key metrics, including the projected attack rate and peak infectious percentage. The chart visualizes the outbreak trajectory. It's important to note that this tool provides relative scenario comparisons, not medical forecasts."

**Sensitivity Analysis (1:10 - 1:30)**

"Next is the Sensitivity tab. Because real-world data always has some uncertainty, this tab shows how changing specific inputs affects the outcome. This helps us see if our planned interventions will still work even if the data isn't perfect."

**Comparing Scenarios (1:30 - 1:50)**

"Finally, the Compare tab is where the tool really shines. Here, we can directly compare our baseline against different interventions, such as improving ventilation or wearing masks. As you can see, combining multiple interventions is the most effective way to reduce transmission risk."

**Conclusion (1:50 - 2:00)**

"ClassPass gives schools a clear, data-driven way to plan safer learning environments. Thank you for watching."
